# CoolGames.io

**Free classic browser games** — Chess, Tetris, Snake, Pong, 2048, Wordle, Ludo, and more. No downloads. No accounts. Just play.

**[Play live →](https://a2105z.github.io/CoolGames.io/)**

## Quick start

```bash
git clone https://github.com/a2105z/CoolGames.io.git
cd CoolGames.io
npm install
npm run dev
```

Open http://localhost:5173.
